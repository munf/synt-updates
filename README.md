# synt updates

Public changelog, release notes and docs for **synt**, an audit terminal for new Solana pairs, with a recorder for new BNB Chain launches (four.meme and Flap).

synt screens every new pair and publishes a full audit for the ones that pass. Every audit score is shown next to its measured base rate, from both sides: how many pairs at that score collapsed, and how many rose 3×. A score describes risk. It is not a promise about any single token.

- Site: https://synt.fun
- Terminal preview (free, no wallet needed): https://preview.synt.fun
- Data notes: https://preview.synt.fun/discovery

The engine, its scoring rules and its thresholds stay private. This repo only holds public notes about the product.
